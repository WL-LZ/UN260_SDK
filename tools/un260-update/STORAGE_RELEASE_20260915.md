# 升级空间发布约束

本次故障：设备 root_free=16516 KiB，changed=8，暂存14523 KiB，
加2048 KiB安全余量后需16571 KiB。失败发生在写入前，非校验失败。

两套 boot-light.bin 是主机像素测试的未压缩对照数据，各2596880字节。
正式渲染器使用内嵌压缩数组，不读取这些文件。对照数据改在
aic_ui/generated_assets 下生成；安装排除同名文件；Buildroot只清理
构建目标目录中两条明确的历史路径；打包器再次拒绝这些测试文件。
不在设备上主动删除历史文件，不改设备空间预检和回滚机制。

check_storage_budget.py 在发布前对固定基线和上一次输出分别计算变化文件，
按设备规则逐文件向上取KiB并加4 KiB，再保留2048 KiB。
发布资格为根分区至少16384 KiB可用；超过预算会终止打包，保留上次输出。
首次没有基线时只受单文件/总载荷预算约束，首次完整固件部署建立基线。
跨任意未验证旧版本、额外用户数据占满空间不在此主机资格保证范围，
设备仍按实际空闲空间拒绝不安全安装。不能以UPK压缩大小代替暂存预算。

测试：test_storage_budget.py、test_package_budget.sh、test_updater.sh、
test_fast_delta.py，以及C/D原生动画像素与接管测试。
主机故障注入不等于真实闪存断电验证，最终需板上升级验证。
