# 机器异常引导移植

## 协议与状态

- `0x0A` 点钞启动：`01/01` 成功；`01/02` 未放钞仅为顶部 INFO。`02/01…0D` 等实际异常进入机器引导。设置命令被拒绝不再伪装成启动异常。
- `0x0F` 运行异常：已知 `01…07` 自动展示对应引导，未知码保留原始代码并使用受限频率的顶部消息，可从机器状态入口查看。`00` 仅清除启动/运行来源，不能清除独立自检或传感器故障。
- `0x37` 自检：仅接受原自检窗口内、原顺序验证通过的回包。各步骤独立保存失败/恢复，完成自检流程后统一显示所有异常；不再只保留第一项失败。
- `0x02/01` 初始化传感器状态：完整十字节帧中 `buf[5..8]` 为高字节在前的 32 位故障快照。映射 bit1 PS1、bit2 PS2、bit3 PS5L、bit4 PS5R、bit23 MP、bit31 IMG；其他置位保留代码而不猜测具体部件。
- `0x14` 传感器忙/闲反馈不是故障位图，不新增或清除机器故障；畸形短帧也不清故障。

所有来源的活动故障归 `machine_state/machine_fault` 所有，LVGL 弹窗只负责展示。Confirm 记录“已读”并切换到下一条未读异常或关闭引导，**不发送串口指令、不重试点钞、不声称故障已修复**。同一活动异常确认后不反复弹出，新异常重新提醒；只有相应设备恢复回报清除活动状态。已读但未恢复的故障可通过 Main 的机器状态入口重新打开，显式 Run 仍按原业务流程重新检查。

原 `0x3D` UI 自动确认/口袋确认/定时重试链已删除；现有协议资料没有给该链提供明确 ACK 语义。打印 `0x3C` 有“完成”帧但未定义结果字节及事务匹配关系，因此只显示“请求已发送”，不把任意完成帧臆判为本次成功。

## 模型和交互

- 固定 1280×400 设计：卡片 1208×370，模型舞台 510×273。位置文本与安全提示在舞台下方左对齐；代码保留且与主要步骤信息分层。
- 模型依据已批准的 SVG 结构生成透明图层：接钞口位于正面底部；上币道覆盖两排滚轮；背面下币道有上方缝隙并按抽屉方向拉开；侧面图像板、主板分别在下方左/右；大码盘保持圆形。MP 无法区分两码盘时共同强调，不虚构单个定位。
- 打开引导即循环当前步骤；手动切换步骤才切换动画。暂停、重播与多故障列表独立；收到其他故障恢复位不重启当前步骤。
- 有可靠动作的故障播放处理步骤；位置未知或内部故障只做重点高亮及简短处理提示，不制作推测性的拆机指引。

## 实现和维护

- `fault_guide_catalog.c` 维护类型、短文案、视角、区域及动作映射；`machine_fault_view.c` 负责分层绘制和动画；`lv_fault_popup.c` 负责交互和生命周期。协议路由不放在绘图组件中。
- 18 个预渲染图层共 1,425,384 字节常量图像数据，生成时限定在 2 MiB 内。运行时没有逐帧图片解码、文件读写或缩放；只改变图层位置/可见性及强调区域。隐藏/销毁停止对应动画和定时器。
- `tools/gen_machine_fault_assets.py` 在 CMake 配置时生成 BGRA C 资源。可维护的 PNG/SVG 和位置清单保存在 `tools/icon_sources/fault_guide`；生成 C 位于忽略目录。
- 通知和机器引导通过局部字体包装保留原 Instrument Sans 英文排版，并回退到开源 CJK 子集。`tools/gen_message_fonts.py --check` 检查现有文本覆盖；再生需要已安装的字体转换工具，不自动联网。OFL 许可随固件安装。
- 52 张退役图片保存于 Linux `/home/pc/un260-archives/20260929-fault-notice/retired-fault-images.tar.gz`，逐项 SHA-256 见 `retired_fault_assets.json`。仍被自检使用的 `0a00_err.png` 保留。构建安装只清理清单中且哈希相符的旧图片，遇到同名改动文件停止并保留。
- 另有两张零引用的 List/Menu 旧背景及对应 C 数组保存于同目录 `retired-unused-ui-assets.tar.gz`，逐项记录于 `retired_unused_ui_assets.json`。移除其 CMake 项和声明后，原有画面不变，消除 3,072,032 字节死图像常量；安装清理清单合计 54 张图片。完整打包沿用原应用与根分区容量检查，没有降低门槛。

## 验证边界

纯状态、协议回放与真实 LVGL 离屏测试覆盖确认去重、来源独立恢复、未知位、短帧、分步循环、暂停重播、外部销毁、多语言字形、通知收起与异步结果。交叉构建和完整 make/升级包核对另记在交付记录。

上述验证不替代板上的触摸手感、显示驱动负载和串口实机联调；不承诺未经板测的帧率提升比例。页面原有非通知区域的中韩字体问题不属于本次消息字体回退范围。
