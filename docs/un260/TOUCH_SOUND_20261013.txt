UN260 触摸声音反馈（2026-10-13 初版，2026-10-14 修订）

目的与人机交互规则
短音只表示 UI 接受触摸操作，不承诺主控命令成功。主控成功/失败确认、故障提示和视觉按压反馈保留。短音统一、单次、有限频，避免把普通触摸做成报警或连鸣。

何时响
1. 可用按钮、选项、复选框、输入框、下拉框和键盘的有效点击。
2. 自定义命中判定确认的 Main 详情入口、List Search 结果、History 记录与选择、现金记录、通知关闭。
3. 调整控件的有效点按最多一次；滑块、滚轮和布局拖动属于手势，不响。
4. 注册了长按动作的控件在首次长按时最多一次；后续重复长按和松手不重复。

何时不响
空白、禁用或隐藏控件、滑出取消、列表滚动、所有返回/开合/滑动/拖动手势和程序触发的非触摸事件不响。屏幕操作音关闭时不响；机器声音开关独立。有效点按不再按页面或动作执行后的机器状态二次抑制；由原控件决定操作是否可用，串口未就绪时不发送。

协议与生命周期
保留原 0x15 机器声音设置和确认语义；使用新 0x4A/01 开、0x4A/02 关。复用现有 protocol_frame_build、protocol_send 和串口发送互斥；沿用项目已有帧尾规则，不新增或猜测 CRC 算法。
目标时长 35 ms，起音间隔至少 120 ms。同一触摸去重；忙时不排队补响，不延长已有短音。串口生命周期创建/回收一个蜂鸣器线程；线程不访问 LVGL 或页面模型，不为每次触摸创建线程或分配内存。UI 卡顿期间关闭计时仍运行。
不重发开命令。关命令等待 120 ms 确认，最多发送 3 次；未确认关闭时禁用起音；迟到的有效 OFF 确认可恢复。没有确认时，后续触摸最多每秒请求一次 OFF 恢复探测（每轮最多 3 次），探测期间不发 ON、不补播旧点击，确认关闭后仅下一次新触摸可响。RX 线程在入 UI 队列之前观察 ACK，页面重建不能拖延关闭确认。退出在关闭串口前停止线程并尽力关闭仍属本服务的蜂鸣器。线程创建失败只失去声音反馈，不阻断机器通信。

模块边界
gesture/touch_sound：输入接收、控件判定、滑动取消、长按与冒泡去重。
app_service/app_touch_sound：统一已接受点按的声音请求，读取独立的 user_cfg 屏幕操作音设置并检查串口就绪。
app_service/buzzer_service：独立计时、0x4A 发送、确认与失败关闭策略。
lv_port_indev：可选反馈与物理接触观察器，保留原按压/捕获/滑动逻辑。
LVGL 通过正式包补丁 0016 新增只读事件过滤查询，不公开私有描述符，也不改变对象结构或事件派发语义。自定义列表在其原有接受分支发 READY 事件，不新增页面串口依赖。

主机验证范围
新增测试覆盖实际 LVGL 与 evdev_feedback：点击、禁用/空白、滑出取消再点击、长按、事件冒泡、滚动、程序事件、对象删除/重建、键盘禁用键、滑块松手及自定义接受事件。
工作线程测试覆盖帧字节、独立关鸣、快速请求合并、关闭确认、无确认、失败确认、开命令发送失败、迟到确认恢复、退出/重复退出与重启。
策略测试覆盖独立静音、串口未就绪、动作后状态变化不漏发与请求合并；另运行现有触摸校准、点钞协议、下拉捕获和主界面回归。
历史完整套件中的 test_search_modes.c:143 仍有 Main NO=105 的旧断言失败；使用本任务开始前保存的 History/List Search 页面源码同样复现。未修改这条无关断言。仓库外专项运行保留 List Search 与 History 测试，仅移除对该 Main 子测试的调用，详细结果见随包日志。

板上必须验证
35 ms 是软件目标时长，电气起止受 Linux 调度、串口发送和主控执行延迟影响。请测试主观音长/音量、快速输入、连续翻页、机器声音开关、主控原有按键音是否叠加，以及报警恰好发生在短音期间的优先级。
目前协议没有自动截止时长、事务编号或报警所有权字段：不能仅凭此协议保证一个同时出现的主控报警绝不被 0x4A 关闭影响。串口物理断开或 UI 进程被强制终止时也不能保证最后的 OFF 到达；若主控无自身超时保护，应在主控侧增加短音自动截止/报警优先仲裁。
本次未进行板上刷机或实机听音，不以主机测试和构建成功代替触摸、声音和主控兼容验证。
