UN260 屏幕操作音修订（2026-10-14）

修复依据
1. 旧版 OFF 确认走 UI 分发队列，页面构建或切换阻塞超过 3×120ms 时，声音服务永久禁用。改为 RX 验证完整帧后、进入 UI 队列前观察 4A 回复；保留原队列顺序和其他业务处理。UI 分发不重复处理确认。
2. 旧版声音层独立按位移取消，会与普通按钮的有效点击不一致。声音跟随原控件的有效点击、取消、滚动和失去触摸事件；不再给普通按钮加第二套位移阈值。测试覆盖主页 Batch 同类普通对象按钮的小幅移动点击。
3. 显式捕获的快捷面板触摸不会走普通 CLICKED 物理路径，新增物理接触范围去重，并在原动作接受点标记 READY。补充 MULTI 明细点选、布局按钮、快捷面板有效点按；所有手势路径不发布声音接受标记。
4. 屏幕操作音与 0x15 机器声音设置脱钩。新增 touch_sound.cfg（默认开），用现有原子保存接口持久化，失败保留原值；工厂复位同时清理正式/临时文件。

统一标准
声音表示“UI 收到一次有效操作”，不表示主控执行成功；原协议成功/失败反馈仍独立生效。
会响：可用按钮、MDC/Batch/Speed/Sort 轮询、菜单/返回按钮、开关、选项、键盘、下拉选项、自定义列表中已命中的可操作条目、快捷面板有效点按、布局操作按钮。
调整控件：有效点按最多一次；有长按动作的普通控件只响一次，按住和重复触发不连续响。
不响：返回/侧边栏退出/面板开合等手势、滑动翻页、滑块/滚轮/布局拖动、空白、禁用/隐藏控件、取消或未命中的操作、后台刷新、程序事件；页面展示本身不响。
统一策略：有效点按不按按钮名称、轮询功能、所在页面或动作后的机器状态二次抑制；由原控件可用性决定是否接受操作。屏幕声音关闭或串口未就绪时不发送。
音长目标 35ms，起音间隔至少 120ms；忙时合并/丢弃，不排队补响。关闭屏幕操作音即刻静音（关闭这次也不响），打开后新有效操作恢复。机器声音开关继续只使用原 0x15 协议确认，不被屏幕开关改写。

设置设计
Preferences / Display & sound 的 Sound 卡片分为 Machine sound（机器提示音）和 Touch sound（屏幕操作音）两行，状态与开关对齐，整行可点击。待机时间归到 Display 卡片。没有新增设置入口分叉。
三条新文案已接入全部十种语言，使用现有字体；检查新界面全部标签的完整单行宽度与字形，俄文待机标题使用足够宽度，不缩小字号。

安全恢复和生命周期
不重发 ON。关闭失败或未确认时，只允许 OFF 恢复探测；迟到的有效 OFF 确认可以解除暂时静音。无确认的恢复探测最多每秒一轮，每轮最多三次关闭指令。确认前不能起音，探测成功也不补播触摸。UART 关闭前停止线程；RX 观察器在启动前注册、RX 停止后清除。
共享蜂鸣器协议没有报警所有权、自动截止或事务编号，实际故障音优先级、0x15 关闭时主控是否仍执行 0x4A、音长/音量与重复按键音仍需实机联调。软件不会声称仅凭这些接口保证物理断线后 OFF 必达。

验证范围

真实 LVGL 输入：有效/禁用/空白、轻微移动、取消后重按、长按、删除重建、键盘、滑块、日期滚轮；真实菜单捕获路径检查快捷操作恰好响一次、翻页不响、进出设置后再次操作；全语言声音页面单行/字形检查。
