# 统一滚动条接入规范

入口：`un260/lv_components/ui_scrollbar.h`。

- `main.c` 在显示注册后安装扩展主题。后续原生滚动容器自动采用公共绘制，不要再创建页面私有滑块或用文本字符画箭头。
- 原生容器需同时具备 `CLICKABLE`、`SCROLLABLE`；需要弹性回弹时保留 `SCROLL_ELASTIC`。拖动注册不能代替触摸命中标志。按既有输入规范调用 `lv_port_indev_set_drag_obj`。
- 自定义物理滚动使用 `ui_scrollbar_create` 和 `ui_scrollbar_update`；传入实际视口、内容长度及**含越界量**的偏移。组件只负责显示，不修改数据位置或业务选择。不要把偏移先截断再传入。
- 三角、间隙、滑块均在原轨道长度内布局；不足一屏时不显示；不足 10 像素的轨道不强行绘制。10 像素及以上会缩小端部间隙/三角，避免超界。
- 三角是方向提示，不是按钮。不新增边缘触摸抢占，不改变全局多指手势。
- 滑块越界时在对应端收缩；原生 LVGL 或自定义物理模块负责松手后的回弹，组件没有独立定时器。
- 自定义滚动条私有状态随对象 DELETE 释放，用户数据归组件所有；外部不得覆盖其 user_data。每帧无分配、无存储读写。
- 保留 `LV_SCROLLBAR_MODE_OFF` 的页面不会被强制加滚动条；分页而非滚动时隐藏。
- 测试应覆盖上下两端、短轨道、空内容、拖动后的点击抑制、销毁/重建、手势及滚动数据更新。

旧的“中间 40% 透明、边缘不透明”已由统一颜色及形变反馈替代。
