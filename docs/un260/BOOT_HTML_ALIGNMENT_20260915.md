本轮参考本地 UN260-Arrival-Flow.html 实际代码，而不是上一轮对称渐隐方案。

## 已实现

- Welcome在0.55秒开始、1.75秒渐显；7.4秒开始、0.65秒渐隐。三轮最后一个小点在7.3秒落下，随后约0.1秒进入渐隐，不再额外等待完整周期加1.75秒。
- 小点每轮1.8秒，错峰0.15秒，起落0.9秒，幅度5像素；原生/LVGL使用同一个离线采样的sin²曲线，无每帧三角函数计算。初始化异常或未就绪仍走原有保护，不用动画强制跳过系统准备。
- 当前页面背景全部统一为Main的backgrounds/user.png，设置和Pure也统一（遵照本轮最新要求）。开机/自检背景从该图片离线叠加品牌和页脚，底色完全同源，不重新制作另一套配色。
- 握手等待采用U盘升级同类lv_spinner，900ms/72°，28px，灰色底环、蓝色活动弧。隐藏、握手结束、故障、销毁时停止并删除，不持续消耗后台动画资源。
- 自检正文原本已是Roboto：标题36px Regular，项目16px Regular，状态及辅助信息12px Regular，保持清晰层级，不做伪粗体；图标勾号仍用符号字体。
- 卡片增加8px宽、下偏移2px、约7%不透明度的灰蓝浅阴影，随卡片入场/退场同步改变。
- Ready遗漏的底轨和SELF-CHECK标题已纳入渐隐；纯Ready阶段没有底线、百分比或辅助标题残留。

## 升级方式——重要

本轮修改了提前亮屏程序的动画曲线/时间轴，视觉版本更新到6。
