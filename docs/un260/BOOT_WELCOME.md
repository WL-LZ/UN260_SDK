# 手写 Welcome 开机版本（2026-09-15）

## 范围

在现有第三套 C 动画中使用深色 `#101418`、文字 `#F2F4F5`、品牌橙 `#F85820`。
图标与 Open Runde UN260 同步渐显，UN260 渐隐后，手写 Welcome 整体渐显。
没有实时描边、每帧解码、每帧字体排版或缩放；手写字是完整预排版字形，避免逐字显现割断连笔。

普通字体：Open Runde Medium，启动和自检范围使用 24/40/48px 子集。
欢迎字：Oooh Baby，构建维护阶段预排版为 446×112、4bpp 的独立 U+E000 字形（24976 字节）。
两者遵循 SIL OFL 1.1，许可随镜像和 UI 资源包安装在 `boot_theme_c/licenses/`。
没有使用 Apple 的字体、图标或动画文件。

## 时间与所有权

共享 `boot_welcome_timing.h`：0–600ms 同步渐显，600–900ms 品牌字渐隐，900–1550ms Welcome 渐显，2180ms 后允许开始原有 320ms 自检揭幕。
原生首帧保留既有的 450ms 可见起点；接管继承已经播放的时间，不重新开场。
约 2.5 秒是视觉时间轴，不是按下电源到完成自检的承诺。
真实初始化和下一页准备尚未完成时继续等待；取消原先就绪后强制三轮小球。
没有绕过正式握手、自检、失败确认或进入主界面的安全条件；异常仍进入 SENSOR。

原生绘制保留 RAM 合成、双缓冲、VSYNC、单写入者租约；等待时只复制 41×13 区域。
动画退出删除定时器并释放私有图片缓存。触摸、点钞、存储、普通页面刷新周期和 LVGL 库未调整。
自检列表增加可选字体配置，默认字体不变；只有启动页选择 Open Runde，并给 Loading... / 100% 留足空间。

## 字体来源和再生成

- Open Runde 固定源：`https://github.com/lauridskern/open-runde/tree/3e7ed7f3cdfa5523766db7e430066472615fc935`。
- Oooh Baby 源：`https://github.com/google/fonts/tree/main/ofl/ooohbaby`，实际字体文件已随源码保留，不在设备启动时下载。
- `tools/gen_boot_fonts.sh` 需要已安装的 lv_font_conv，产生 LVGL 8.3 兼容、不压缩、无 kerning 的 ASCII 字体。
- `tools/gen_boot_welcome.py` 需要主机 Pillow >=10，仅字体美术调整时运行；普通固件构建复用已生成 C。
- `tools/build_boot_light_assets.py` 从同一 C 字形生成早期原生资源，避免不同字体引擎在接管时变形。
