阅读页面调用、设置服务、权限、记录数据与持久化边界。主机测试运行真实 LVGL，不能替代连接主控后的触摸与协议验收。

01 Overview
检查：币种独立汇总；金额只取已确认清点记录；数量来源；Batch/Options/Calculator/Journal入口；切换操作员不更改全局历史。
结果：保留现有语义。Overview 的 confirmed total 是清点记录汇总，不当成现金账本余额。

02 Count / Batch presets
检查：固定OFF、数量范围1~199、至少一个数值档、编辑/取消/保存、保存后应用、存储失败与主控ACK分离。
结果：保留此前修复；原生Menu与workspace服务测试覆盖。未ACK不把本地草稿标成机器已生效。

03 Count / Profiles
发现：profile_matches没有比较beep，且“Keep current”模式错误地要求与当前模式数值相等。
修复：比较声音；mode=0按不改变模式处理；详情补显示Sound。列表缩进保留，并预留20px滚动条空间。
验证：完全匹配、只声音不同、mode=0、长列表滚动选中和边界断言。

04 Count / Options
检查：模式、速度、Start、ADD、排序、Reject上限、Batch入口；同值选择；协议提交失败与异步提示。
结果：保留主控确认流程和当前运行时必要保护。不能以“只允许主控拦截”为由删除存储提交保护或伪造ACK。17个Menu修改边界、8类协议设置及提示路由检查通过。

05 Records / Daily totals, History, Day closes
发现：业务日期草稿在确认前覆盖本地日期，取消也改变列表。
修复：当前记录日期以持久化数据为准；归档的日期仅作为筛选。取消确认保持原日期。
检查：选中记录、版本检查、确认/排除、重复清点、关闭日、只读归档、QR和导出边界；金额卡多币种滚动留位。
结果：历史与现金账保持独立；不删除原始点钞记录。现有模型/视图测试覆盖关闭日、选中结果与只读边界。

06 Output / Print, Layout, QR
检查：打印配置字段映射、空白行0~99、标题长度、设置ACK、运行中打印、自动QR与手动QR、MULTI区分、不完整数据。
结果：保留实际打印协议；打印/QR不可用时保留明确状态。自动QR测试覆盖新结果、故障、切页与手动所有权。

07 Preferences / Operators
检查：简版查看/切换与详情管理分离、全设备管理开关、稳定ID、首字母居中、滚动/分页、重命名、删除引用校验。
修复：操作员及账本权限入口开启四位自动验证；错误清空；连续输错显示真实剩余等待秒数。授权不切换操作员。
结果：有历史/现金引用的操作员仍不能物理删除；停用保留关联。这是记录完整性规则，详情已说明并提供停用/恢复。无引用者可删除，测试覆盖。

08 Preferences / Interaction
发现：Shortcut右列占满容器；选择时重建页面没有保存此列表的滚动位置。
修复：复用公共滚动内容宽度，预留20px；两列等宽、文字左对齐、去掉普通/选中项边框，以背景表达选中；接入原有滚动位置保存机制。
公共修复：新建容器查询内容宽度前完成布局，避免未布局宽度引起列宽错误。
检查：关闭/打开Top popup不会取消业务或重放过期提示；快捷排序写入失败恢复原值；手势/布局等本地设置按自己的持久化结果反馈。

09 Preferences / Display & sound
检查：Machine sound按钮与文字处于背景内、待机输入0~60、显示图形、语言名称和字体、待机故障复核。
结果：原修复保留，原生渲染核对。未更换现有主色或给按钮加边框。

10 Help / Reject, Care, Device
修复：Reject列表同样预留滚动条空间。
检查：0x00~0x31各错误说明布局；未知码回退；设备版本无连接状态；维护步骤；导出不含密码/冠字号/金额等数据。
结果：保留原来说明和设备状态。屏幕板未接主控时的Handshake4超时不当成UI故障。

11 公共导航、键盘、生命周期
检查：草稿离开确认、键盘外点取消、Quick关闭、页面隐藏/恢复/销毁、异步通知独立所有者。
修复：PIN第四位仅在由未满转为已满时提交，防止满4位继续点数字重复授权；改密码页也使用密码入口紧凑布局。金额/汇率保留明确Apply，不使用4位自动提交。
语言：Quick动态notes单位接入语言；新增锁定提示进入语言目录及字体生成。可见文本静态审计0未标记sink，不表示所有旧文案均有三语翻译。
