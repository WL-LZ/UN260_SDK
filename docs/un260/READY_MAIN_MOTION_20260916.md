## 实现

- 真实五项成功后，自检卡片错时退场；进度线、底线、百分比一起隐藏。
- Main 同款背景上显示居中的确认标记、`Ready to count.`、`Precision starts here.`。
- 静止就绪后才允许原有隐藏页面预热；握手、失败/超时、面额数据、最终导航仍归原业务服务管理，不按动画时间伪造成功。
- Main 私有模块管理一次性入场：左栏、摘要、详情、右栏、底栏错时 65 ms；19 px 上浮、1 px 轻回落，结束恢复原始偏移。
- 不移植浏览器整组缩放、透明控件层、截图缓存。使用现有一张背景图透明混合作为交接，900 ms；这仍有整屏绘制开销，不能视为零成本。
- 固定 64 项工作集、一个短生命周期定时器；不每帧申请对象、解码资源或读文件。重复调用、页面暂停、销毁都清理位移与定时器。超出工作集或定时器失败静态回退。
- 顶层交接遮罩延续触摸拦截；Pure 保留淡入，不执行 Main 的分区位移。
- `UI_MAIN_ENTRANCE_ENABLE=0` 可关闭分区位移；已有 `UI_BOOT_HANDOFF_FADE_ENABLE=0` 可关闭整屏淡入。四套开机宏保持有效。
