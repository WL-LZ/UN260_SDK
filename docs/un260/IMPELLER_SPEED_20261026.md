# 叶轮电机调速（0x4B）

入口为“设置 → 维护 → 叶轮电机调速”，使用现有设置页组件与导航。范围为 15–50，默认 30；数值不额外标记为转速或百分比。支持滑条、加减和数字输入。默认按钮只修改草稿，保存按钮才发送主控设置命令。

## 最新协议

以用户最后提供的 0x4B 协议图为准；0x4A 仍为原有触摸声音协议。

| 方向 | 含义 | 帧（末字节沿用项目封帧规则） |
| --- | --- | --- |
| UI → 主控 | 读取 | FD DF 06 4B 01 CRC |
| UI → 主控 | 设置 | FD DF 07 4B 02 XX CRC |

进入页面时读取一次，不在开机时查询或自动写入默认值。初始 30 是未确认值；只有有效读取回复或设置成功回复才更新主控确认值。

## 状态与职责

- `setting_service` 拥有该命令的读写事务，`machine_state` 保存最后确认值及是否确认，页面只处理草稿和展示。
- 同一条 0x4B 事务等待期间，读取和保存暂不可重复提交；数值编辑、默认和返回仍可操作，不引入全局 busy 或其它页面锁。
- 超时沿用 800 ms 请求机制，释放事务，保留数值并标为未确认，允许用户重新读取或保存。不自动重发写命令。
- 设置失败保留旧确认值。读取失败不能证明当前值，保留数值并标为未确认。错误码显示为 `0x4B/0x03`。
- 离开页面不会取消已经发送的命令。回包仍更新模型，页面销毁后的通知安全返回；用户在等待期间新编辑的草稿不会被旧回包覆盖。
- 读取属于页面同步：自动进入或手动读取的发送失败、明确拒绝、超时都只在所属页显示状态，不发全局抬头提示，退出后不打扰其它页面。主动保存仍保留成功、明确拒绝与无回复的准确反馈。
- 已确认的同值保存不重复发送；未确认时可以同值重试。
- 所有新增可见文案进入十种语言目录，并更新必要的语言字体和消息字体。
